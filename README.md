# Daily Wisdom

A small multilingual web application that presents short wisdom and quote cards with category filtering and sharing tools.

## Features

- Arabic, English, Chinese, and Russian interfaces
- Quote categories such as wisdom, inspiration, success, and life
- New-quote interaction
- Copy-to-clipboard support
- Share interaction
- Responsive layout
- Dark-mode styling

## Technology

- HTML
- CSS
- Vanilla JavaScript

## Run locally

Open index.html directly in a browser, or serve the directory with any static HTTP server.

## Portfolio context

This is a compact frontend project demonstrating responsive UI work and multilingual client-side interaction. It is intentionally kept as a small supporting repository.
